# Thinking Outside v1.0.0-rc.1

**First installable release candidate for the revised D architecture.** This is a **prerelease**, not the stable 1.0.

## Highlights

- **Explore → Evaluate → Evolve:** generate structurally different mechanisms, compare them against constraints and refine viable options with measurable tests.
- **Direct response path:** avoid unnecessary ideation for factual, tightly scoped or safety-critical requests.
- **Originality without empty novelty:** detect cosmetic duplicates and qualify unsupported claims.
- **Portable Agent Skills layout:** a plain Markdown skill with references; no dedicated MCP, model or server required.
- **Open evaluation evidence:** frozen historical versions, isolated Codex runs, anonymous automated scoring and validated human-review tools.

## What was measured

In a pooled eight-family automated benchmark, revised D received **84.4% tie-adjusted preference** against the agent without the skill and **78.1%** against the previous B variant, over 16 matched comparisons against each control. One automated reviewer judged anonymized outputs; the results should not be treated as independent human verification or universal superiority. The 15 canonical rubric checks produced 13 passes, two noncritical concerns and no automated critical flags.

Read the [complete report](https://github.com/God-601/Thinking-Outside/blob/main/docs/review-1.0.md) and the [evaluation protocol](https://github.com/God-601/Thinking-Outside/blob/main/docs/benchmark.md).

## Known limitations

- Two independent human blind reviews are still pending.
- Explicit Codex skill loading was confirmed, but automatic loading remains unverified in recorded runs.
- Claude Code was blocked in the recorded CLI probe; a later user-supplied Sonnet 5.5 Medium marker test supports explicit invocation without proving automatic activation.
- OpenCode and Cursor native behavior have not been tested.
- The skill does not guarantee novelty, superior results across all tasks, or token savings.

## Install

Download **`thinking-outside-v1.0.0-rc.1.zip`** and verify its SHA-256 against the included `.sha256` asset. Extract the `thinking-outside/` folder into your agent's project skills directory:

- Codex: `.agents/skills/thinking-outside/`, then invoke `$thinking-outside`.
- Claude Code: `.claude/skills/thinking-outside/`, then invoke `/thinking-outside`.

See the [installation guide](https://github.com/God-601/Thinking-Outside/blob/main/docs/install-candidate.md). Do not install the benchmarking fixtures in place of the skill.
