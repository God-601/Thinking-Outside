# Mechanism exploration: rationale and limits

The previous skill asked for causal diversity but did not specify how to detect duplicates. Its concrete game examples could also supply entire answers. These are hypotheses from inspection and prior diagnostics, not established causal findings.

This candidate adds a causal comparison (trigger → state change → result), checks shared dependencies and failure modes, separates exploration from presentation, and makes candidate replacement conditional on actual convergence. It retains the conventional route as a usefulness control. Abstract contrasts replace the concrete idea bank; they are consulted after drafting.

Methods are selected by obstacles, not a domain-specific recipe. Contradiction separation, morphological decomposition/recombination, distant causal transfer, competing hypotheses and a small premortem complement the existing lateral thinking, SCAMPER, first principles and systems techniques. A method earns its context cost only if it changes a candidate or a test.

## Sources that informed hypotheses

- [Doshi and Hauser, 2024](https://doi.org/10.1126/sciadv.adn5290) report individual creativity benefits alongside reduced collective diversity in a story-writing experiment. This motivates measuring both usefulness and mechanism diversity; it does not establish benefits for this skill or technical domains.
- [Self-Refine, NeurIPS 2023](https://arxiv.org/abs/2303.17651) studies iterative feedback/refinement on multiple tasks. Here refinement is bounded to an identified weakness; self-criticism is not independent validation. The implementation is an instruction, not a reproduction of that paper's system.
- [Agent Skills specification](https://agentskills.io/specification) defines portable metadata, directory naming and progressive disclosure. Runtime needs no Python, model API, MCP or server; benchmark tooling is optional development infrastructure.

The ablation tests example-free, abstract and concrete-example bundles. It is small and exploratory. It cannot prove that examples universally harm creativity, or that the selected architecture is optimal. The baseline is the current main at f41c4d0, not an imagined historical model response.

No hard rule rejects the first N ideas: an obvious correct answer may be the best one. No fixed number of techniques, personas or iterations is required. Creativity never changes mandatory constraints, safety validation or approved decisions.
