# Roadmap

## v0.1 completed
Initial adaptive creativity guidance, reference methods and fifteen planned scenarios.

## Quality hardening (pre-1.0)
- Normalize canonical skill folder naming.
- Improve examples, user-goal preservation and useful reframing.
- Migrate evaluations to Skill Creator-compatible schema.
- Add positive and negative skill activation prompts.
- Add repeatable human-review scoring and regression tests.
- Run static checks and Agent Skills reference validator in CI.

## v1.0 publication
Only after real-agent tests, blind human reviews, critical-safety and user-constraint gates, verified installation and maintainer review.

There is no predetermined publication date. Structural correctness is necessary but not sufficient.
