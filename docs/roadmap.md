# Roadmap (proposal; not a release promise)

| Version | Milestone | Exit criterion |
|---|---|---|
| v0.1.0 experimental | Minimal skill, reference methods, documentation, baseline evaluation cases | Structural validation passes; real-agent behavioral testing pending |
| v0.2 | Adaptive idea generation and filtering | Distinct mechanisms improve over baseline on selected scenarios |
| v0.3 | Selective problem reframing | Appropriately reframes hard tasks and leaves clear requests intact |
| v0.4 | Anti-generic quality and efficiency | Less repetition without cost/latency explosion; no hard-constraint regression |
| v0.5–0.9 | Cross-agent compatibility and comparative evaluation | Comparable runs on available agents and competitors, documented limitations |
| v1.0 | Stable public release | User review, A/B evidence, installation docs and tracked known limitations |

**No v1.0 release before behavioral evidence.** No paid infrastructure is required by the core skill. GitHub-hosted features may have service limits.
